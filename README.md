
# TapFixAR – DIY Repair Assistant

## About the Project
TapFixAR is a Final Year Project developed by a three-member Diploma in Information Technology team at Politeknik Ungku Omar.

The project focuses on an Android mobile application that helps users with basic DIY repairs through step-by-step guidance. AI and Augmented Reality (AR) were part of the proposed project concept.

## Technologies Used
- Kotlin
- Android Studio
- Firebase Realtime Database
- Figma (UI/UX Design)

## Project Features
- User registration and login
- Step-by-step DIY repair instructions
- Mobile application interface
- Firebase database integration

## Project Development
Our team worked on UI design, Android application development, database integration, testing, project demonstrations, and documentation.

## What I Learned
- Android application development using Kotlin
- Working with Firebase Realtime Database
- UI/UX design and application testing
- Team collaboration and problem-solving
